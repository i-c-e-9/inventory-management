Architecture overview

Factory Inventory Management System

A two-tier demo app. A Vue 3 single-page app talks to a FastAPI service over REST, and the service holds all data in memory, loaded from JSON files at startup. There is no database, no authentication, and nothing persists.

Data flow: a filter change

What happens when a user picks a warehouse or time period in the filter bar.

  1. FilterBar updates shared state. useFilters.js keeps four module-level refs (period, location, category, status), so every view sees the same values.
  2. The view reacts. Each view watches the filter refs and calls getCurrentFilters(), which renames location to warehouse and period to month.
  3. api.js builds the request. Filters set to 'all' are dropped, and the rest become query params, e.g. GET /api/orders?warehouse=Tokyo&month=Q3-2025.
  4. FastAPI filters in memory. apply_filters() narrows by exact warehouse and case-insensitive category or status. filter_by_month() substring-matches order_date, expanding Qn-2025 through QUARTER_MAP.
  5. Pydantic validates the response. Typed endpoints serialize through response_model. Spending and reports endpoints return raw dicts.
  6. Vue derives what to display. Raw arrays land in refs such as allOrders and inventoryItems. KPIs, chart series, and tables are computed from them.

Data model

Records are linked by SKU and ID strings. Nothing enforces these links; they are just conventions in the JSON.

Notable gaps

Places where the code doesn't match itself or the docs. These are worth knowing before you change anything.

Tasks API is missing on the serverApp.vue calls GET/POST/DELETE/PATCH /api/tasks through api.js, but main.py defines none of these routes. The errors are caught and logged, so only the hard-coded mock tasks from useAuth.js ever appear. Tasks added in the UI never persist.
Purchase-order endpoints are missing tooapi.js defines createPurchaseOrder and getPurchaseOrderByBacklogItem, but the backend has no matching routes and no component calls these functions yet.
Backlog view isn't routedviews/Backlog.vue exists but isn't registered in main.js or linked in the nav. Backlog data only appears on the Dashboard.
Reports bypasses the API clientReports.vue calls axios directly with a hard-coded URL instead of going through api.js.
Some filters don't apply everywhereInventory has no time dimension, so month is ignored there. total_backlog_items in the dashboard summary ignores every filter. The demand, backlog, spending, and reports endpoints take no filters.
Quarters are hard-coded to 2025QUARTER_MAP and the quarterly report only recognize Q1–Q4-2025. Orders from other years are dropped from quarterly results.
